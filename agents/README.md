# Agents

Examples and experiments focused on AI agents—systems that use an LLM to reason, decide, and act toward a goal.

## What belongs here

Focused examples such as basic agents, tool-using agents, planning agents, and other single-agent patterns.

## Purpose in this playground

Demonstrate how agents are built, configured, and run in practice—independent of any single LLM provider.

This folder can contain multiple small, independently runnable examples.
