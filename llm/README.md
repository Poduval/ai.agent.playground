# LLM

Examples and experiments focused on LLM capabilities and model interaction patterns.

## What belongs here

Focused examples such as basic completion, chat, streaming, structured/JSON output, prompt handling, model parameters, multimodal input, and provider-specific capabilities when they illustrate something unique.

## Purpose in this playground

Demonstrate how to work with language models directly—concept-first, with providers treated as implementation choices.

This folder can contain multiple small, independently runnable examples.
