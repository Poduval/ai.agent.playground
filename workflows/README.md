# Workflows

Examples and experiments focused on AI workflows—structured multi-step pipelines that combine models, tools, and control flow.

## What belongs here

Focused examples such as sequential chains, branching flows, human-in-the-loop steps, and durable or graph-based orchestration.

## Purpose in this playground

Show how to compose AI steps into reliable, inspectable processes beyond a single prompt or agent turn.

This folder can contain multiple small, independently runnable examples.
