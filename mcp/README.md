# MCP

Examples and experiments focused on the Model Context Protocol (MCP)—connecting models to tools, resources, and external context through a standard interface.

## What belongs here

Focused examples such as basic MCP servers, tools, resources, prompts, and client integrations.

## Purpose in this playground

Show how MCP is used in practice to expose capabilities to agents and LLM applications.

This folder can contain multiple small, independently runnable examples.
